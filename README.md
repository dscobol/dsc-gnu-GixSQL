# Creating COBOL/PostgreSQL programs with GnuCOBOL using GixSQL

Running this program requires: (Versions used for this example in ()).

- PostgreSQL (14)
- GnuCOBOL (3.2.0)
- GixSQL (1.0.20a)

See the [Instructions](https://dscobol.github.io/docs/) to setup the software required to run these programs.

Then read the README.md file in the First-Example to setup the development environment.
